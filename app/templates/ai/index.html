Configuring Google Gemini Live AI

StudySync seamlessly connects to the official Google Gemini API for live, in-depth academic explanations, code generation, and practice quizzes.

  1. Get a free Gemini API key from Google AI Studio ↗.
  2. Open your local project directory and find the .env file.
  3. Set your key in the .env file:
    GEMINI_API_KEY=your_actual_key_here
  4. Restart the Flask server (python run.py).
💡 Offline Mode: When no key is configured, StudySync still runs smoothly using intelligent rule-based study recommendations!
