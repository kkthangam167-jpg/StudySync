# StudySync — Your Smart Academic Companion 🎓

**StudySync** is a modern, full-stack academic management and intelligent study planning web application designed specifically for university students. Combining deterministic algorithmic scheduling, curriculum progress tracking, collaborative peer study circles, and an AI study assistant powered by the Google Gemini API, StudySync eliminates academic chaos and optimizes daily study habits.

---

## 🌟 Key Features

### 1. 🔐 Student Authentication & Isolated Profiles
- Secure registration and session-based login with hashed passwords (`Werkzeug`).
- Multi-tenant strict data isolation (User A cannot view, access, or modify User B's academic records).
- Customizable academic profiles: Degree program, current semester, preferred study hours (Morning, Afternoon, Evening, Late Night), daily capacity, and theme preferences.
- One-click **Demo Seed Data generator** tailored for 2nd Year B.E. Computer Science & Engineering students (DBMS, Algorithms, OS, Networks).
- Complete account deletion with cascading record cleanup.

### 2. 📊 Smart Academic Dashboard
- Dynamic real-time metrics calculated from live database records:
  - Weekly focus hours & today's focus minutes.
  - Active pending assignments & overdue alerts.
  - Average syllabus completion percentage across enrolled subjects.
  - Milestone badges unlocked.
- Today's class timetable schedule highlighting active day.
- Upcoming examination countdowns.
- Top recommendations generated by the deterministic Priority Engine.
- Quick action modals for instant assignment creation.

### 3. 📝 Assignment & Deadline Tracker
- Full CRUD operations with priority tags (`High`, `Medium`, `Low`) and effort estimates.
- Status management (`Pending`, `In Progress`, `Completed`) with completion timestamps.
- Automated overdue detection and in-app alerts for approaching deadlines (< 24 hours).
- Multi-criteria filtering by subject, priority level, status, and title keyword search.

### 4. 🗓️ Timetable & Examination Calendar
- Weekly schedule view (Monday to Sunday) with subject colors, room locations, and event types (Lectures, Labs, Tutorials, Seminars).
- Overlapping time conflict detection to prevent double-booking.
- Examination calendar with days-remaining countdown badges, venue locations, and syllabus scope notes.

### 5. 📖 Syllabus Mastery & Revision Tracker
- Hierarchical curriculum structure: **Subjects ➔ Units ➔ Topics**.
- Self-assessed understanding rating (1 to 5 stars) and learning status (`Not Started`, `Learning`, `Completed`, `Needs Revision`).
- Real-time progress bar recalculations at unit and subject levels.
- Dedicated "Needs Revision" highlights and one-click "Mark Revised Today" action.

### 6. ⚡ Deterministic Priority Engine
- Transparent, testable Python recommendation engine ranking tasks without black-box opacity.
- **Scoring Formula**:
  $$\text{Score} = \text{Exam Proximity (0–50)} + \text{Deadline Urgency (0–40)} + \text{User Priority (10–30)} + \text{Revision Need (0–30)} + \text{Overdue Boost (45)}$$
- Human-readable transparent explanation provided for every recommendation.

### 7. 🎯 Personalized Study Plan Generator
- Algorithmic study session generator matching daily available hours and preferred study windows.
- Automatically inserts 10-minute cognitive recharge breaks between focus sessions.
- Timetable conflict detection (avoids scheduling study blocks during lectures or exams).
- Modal review before saving: preview, edit, accept, or regenerate.

### 8. 🔄 Smart Rescheduling Engine
- Detects missed study sessions whose scheduled time has passed.
- Scans subsequent days to identify conflict-free slots.
- Presents proposed changes for user confirmation before applying.
- Preserves session history and audit trails by linking rescheduled items to ancestors.

### 9. ⏱️ Focus Timer (Pomodoro)
- Configurable focus blocks (25m, 45m, 50m) and rest breaks (5m, 15m).
- Coursework and task tagging with notes.
- Client-side `localStorage` persistence that survives accidental page reloads.
- Server-side database session logging and milestone evaluation upon completion.

### 10. 📈 Academic Analytics & Insights
- Interactive charts powered by Chart.js:
  - Daily actual vs. planned study hours over the past 7 days.
  - Subject-wise syllabus completion percentages.
- High-level KPIs and completion ratios.
- One-click personal data export to CSV.

### 11. 👥 Study Groups & Collaboration
- Create peer study circles with secure unique invitation codes (e.g. `A1B2C3D4`).
- Shared study goals with collective progress bars.
- Actionable collaborative revision checklists with member assignment.
- Role-based permissions (`Admin`, `Member`) without exposing private student schedules.

### 12. 🏆 Achievement Badges & Consistency
- Verifiable milestone badges awarded for authentic academic activity (focus sessions, completed assignments, topic mastery, group collaboration).
- Healthy consistency philosophy rewarding weekly momentum without stress-inducing punitive daily streaks.

### 13. 🤖 AI Study Assistant (Google Gemini)
- Conversational study partner built with the official `google-genai` Python SDK.
- **Academic Grounding**: Contextually integrates current student's upcoming exams, pending deadlines, and low-confidence topics into prompts.
- **Graceful Fallback**: If `GEMINI_API_KEY` is not configured, the assistant automatically switches to StudySync's deterministic offline intelligence engine, guaranteeing 100% application usability.

- **Backend**: Python 3.12, Flask 3.1.3, Flask-SQLAlchemy 3.1.1, Flask-Login 0.6.3, Werkzeug 3.1.9

## 🚀 Quickstart & Local Installation

### 1. Clone & Setup Directory
```bash
git clone https://github.com/your-username/studysync.git
cd studysync
```

### 2. Create Virtual Environment
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment & Google Gemini API
Copy `.env.example` to `.env`:
```bash
# Windows:
copy .env.example .env

# macOS / Linux:
cp .env.example .env
```

#### Step-by-Step Gemini API Key Setup:
1. Navigate to [Google AI Studio](https://aistudio.google.com/) and sign in with your Google account.
2. Click **"Get API key"** and create a new API key.
3. Open your local `.env` file and paste your key:
```env
GEMINI_API_KEY=AIzaSy...your_actual_api_key_here
GEMINI_MODEL=gemini-2.5-flash
```
4. **Security Notice:**
   - The `.env` file is included in `.gitignore` and must **never** be committed to GitHub.
   - The API key is strictly stored server-side and is never exposed in browser JavaScript.
   - If `GEMINI_API_KEY` is omitted or left as a placeholder, StudySync automatically runs in **Offline Academic Guidance Mode** using deterministic schedule rules.

### 5. Initialize Database & Seed Demo Data
```bash
# Initialize database tables
python run.py init-db

# Seed 2nd year B.E. Computer Science sample coursework & demo user:
python run.py seed-demo
```
**Demo Account Credentials:**
- **Username:** `demo_student`
- **Password:** `password123`

### 6. Run Application
```bash
python run.py
```
Open **[http://127.0.0.1:5000](http://127.0.0.1:5000)** in your browser and visit `/ai-assistant`!

## 🌐 Production Deployment Guide

StudySync is ready for deployment on modern cloud platforms (Render, Railway, Fly.io, or AWS).

### 1. Environment Variables in Production
Set the following environment variables in your cloud hosting dashboard:
- `FLASK_ENV`: `production`
- `SECRET_KEY`: `<generate-a-strong-random-key>`
- `DATABASE_URL`: `postgresql://<user>:<password>@<host>:5432/<dbname>`
- `GEMINI_API_KEY`: `<your-production-gemini-key>`

### 2. Production WSGI Server
On Linux containers, run with Gunicorn:
```bash
gunicorn "run:app" --bind 0.0.0.0:$PORT --workers 2 --threads 4
```

### 3. Health Check
StudySync includes an automated cloud monitor endpoint at `/api/health` that verifies web server responsiveness and active database connectivity.
